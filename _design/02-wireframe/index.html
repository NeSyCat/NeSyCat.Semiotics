NeSyCat · Wireframe · v0.4 · 1728×1080 (16″ MBP scaled)

Editor chrome — pixel-faithful to today.

Each scene is a 1728×1080 frame sized for a 16″ MacBook Pro at default scaling. Sidebar widths, panel sizes, button padding, font weights, kind labels, hotkey chips, JSON-panel header copy, and React Flow controls are pulled directly from components/editor/EditorSidebar.tsx and components/editor/Canvas.tsx. The React Flow canvas itself (shapes, points, wires, JSON spine) is intentionally left as a dot-grid background — it's out of scope for the redesign.

Scene 1 — default state

Signed-in user has just opened a diagram. Left sidebar is a 56-wide icon rail — one button per user-facing slot of Shape<K> from components/editor/types.ts (slots −1…6). File management (search, diagram list, +new) is no longer in the sidebar; it lives in a separate picker. Top toolbar floats over the canvas with two glass buttons. JSON panel collapsed. Zoom cluster bottom-left, sliding with the sidebar.

Sidebar — Shape spine (components/editor/types.ts)

A56 px rail. Logo on top, 22×22, link back to landing.
Bname slot (−1): user-visible label.
Cpoints slot (0): recursive sub-shapes (ShapePoints[K]).
Dkind slot (1): ShapeKind discriminator — empty / triangle / rhombus / circle / rectangle.
Eorder slot (2): scalar number.
Fcolor slot (3): [r, g, b] ∈ [0, 1]³. Glyph fills with the current shape color so the rail doubles as a swatch.
Gtransform slot (4): SpaceTime — translation + rotation + scale (+ created/updated timestamps).
Hequations slot (5): list of Expressions (rational over shape refs).
Iweight slot (6): scalar Mass.
JSlot −2 id intentionally absent — types.ts:29: "Auto-generated, unique, internal — never user-facing."
KButtons 40×40, 6 px radius. Active state tinted with rgba(accent, 0.18) + accent border. Hover swaps to glass-button bg + glass border.
L‹ collapse handle attached to right edge, slides rail to 0 width via --sidebar-offset.

Canvas chrome (Canvas.tsx)

MTop-left toolbar at 12 px from top, 12px + --sidebar-offset from left, slides on collapse with 200 ms transition.
NEach button: panelStyle() + 8 px radius + 6×14 padding, 12 px / 600 wt secondary text.
O"Straight" label toggles to "Smooth" when clicked; tooltip carries the current state.
PJSON button — open state in Scene 4 (panel expands below it, button stays visible above).
QZoom cluster from React Flow's <Controls/>: 28 px buttons stacked, also tracks sidebar offset.

Redesign hooks

File management (search, diagram list, +new) needs a new home — likely a separate picker / file-tree surface, opened via the logo or a dedicated chrome button.
"Kinds ▾" in the top-left toolbar becomes redundant with the rail's kind button — consider merging into the slot-1 dropdown.
Color slot's button doubles as the current-color swatch. Click to open a picker; the swatch updates in place.
Rail order intentionally follows the slot indices (−1 → 6) in types.ts so it reads as the Shape's own field order.

Scene 2 — sidebar collapsed

Click the handle and the sidebar slides to 0 width (200 ms transition, matches EditorSidebar.tsx setting --sidebar-offset to 0px). The handle stays anchored — its left now resolves to 0 — so the user always has an obvious affordance to re-open. The top-left toolbar and the bottom-left zoom cluster slide along with it; the JSON button in the top-right is unaffected.

Handle

TSingle button, 28×64, glass panel with no left border so it visually attaches to the sidebar or canvas edge.
UArrow flips from ‹ (open → close) to › (closed → open) to match the action it triggers.
Vleft: var(--sidebar-offset) with a 200 ms transition — the handle slides in lockstep with the sidebar.
WThe whole sidebar (brand row, search, list) is still mounted under the hood — width 0 + overflow: hidden hides it without unmounting state.

Scene 3 — Kinds menu open

Hovering the "Kinds" button reveals a glass dropdown 6 px below it. Eight rows: five per-kind toggles (in registry order — Empties, Triangles, Rhombuses, Circles, Rectangles) and three orthogonal toggles (Points, Lines, Outlines). Each row is 5×10 padding, 11 px / 500 wt text; on-state colours the dot accent-blue with a 3 px halo and brightens the label to secondary; off rows stay dimmed.

Menu structure (Canvas.tsx 646–660)

KPanel: panelStyle() + 8 px radius, 6×6 padding, minWidth: 220.
LRows iterate geometryRegistry — adding a kind in types.ts auto-extends this menu.
MDot: 6×6 circle, accent at 90% with a 3 px halo when on; transparent + 22% border when off.
NKbd chips: min-width 18, 18 px tall, 1 px glass border, 10 px Mono / 500 wt. Compound shortcuts use two chips side-by-side.
OOutlines off here illustrates the off-state — dimmed label, hollow dot, no kbd hint.
