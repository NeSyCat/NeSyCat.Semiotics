Editor chrome — eight categories, one form per scene.

Each scene draws a form on the canvas that reacts to the currently edited Spine category — weight controls fill density, rotation rotates, scale scales, location translates, number labels, color fills, shape chooses the polygon. A black-on-glass name bar docks at the bottom of the canvas at the same x / width as the Spine; the user types here to edit the selected form's name (LaTeX supported, à la \mathbb{R}). Level / Class / Equations remain temporarily parked at positions 7–9.
