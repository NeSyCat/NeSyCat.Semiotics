NeSyCat · Wireframe · v0.6 · 1728×1080 (16″ MBP scaled)

Editor chrome — pixel-faithful to today.

Each scene is a 1728×1080 frame sized for a 16″ MacBook Pro at default scaling. Sidebar widths, panel sizes, button padding, font weights, JSON-panel header copy, and React Flow controls are pulled directly from components/editor/EditorSidebar.tsx and components/editor/Canvas.tsx. The React Flow canvas itself (shapes, points, wires, JSON spine) is intentionally left as a dot-grid background — it's out of scope for the redesign.

Scene 1 — default state

Signed-in user has just opened a diagram. A top bar holds the logo, one tool button per exposed Shape<K> field (name through weight), and a share-style control for export / diagram data. The canvas uses the full width below the bar. Zoom cluster stays bottom-left.

Scene 5 — name popover

Clicking the name button opens a popover below the top bar, aligned with that tool. Scene 6 — points popover

The points popover is visibility-first — there's no editor for the nested-shape tree itself; points are added via the + buttons that surface on a selected shape (DiagramNode.tsx:514-537). The head's binary visibility dot toggles today's visibility.points flag (store.ts:8).

Scene 7 — kind popover

The kind popover switches among the five ShapeKind keys of ShapePoints in types.ts:38-65 — empty, triangle, rhombus, circle, rectangle. That is the complete set of shape discriminators for nodes; Line (types.ts:137-146) still carries the same kind field — wires are not a separate kind enum. Today shape kind is fixed at creation; this panel assumes a future mutation. Rectangular tiles match the rail; double-click create shortcuts from geometry.ts live in each tile’s tooltip.

Source of truth

AShape.kind: K at types.ts:120; ShapeKind = keyof ShapePoints at types.ts:70 — exactly the five rows. Line extends Shape<K> (types.ts:143-146) and uses the same kind; diagram edges are not a sixth discriminator.
BEach column: per-kind visibility toggle (head-vis-toggle, same chrome as the panel header); drag tile creates that kind on the canvas.
CToday: no kind-change mutation in mutations.ts; kind is only set at addNode() creation time. Drag-to-create is the primary affordance.

Scene 9 — color popover

The color popover is a full HSV picker — smooth annular hue ring (conic spectrum), inner S/V square, four corner actions (white / black / eyedropper / transparency), opacity under the wheel, HSB sliders, and swatches. Mirrors the Adobe Fresco Color panel layout. Today there's no picker. Shapes initialise to DEFAULT_COLOR = [59/255, 130/255, 246/255] from color.ts:5 and never change.

Scene 12 — weight popover

The weight popover is the continuous twin of Scene 8 — same Fresco-style slider, but with 1-decimal floats and no integer snap. Mass is a scalar alias for number (types.ts:104); today every shape initialises to 1 at mutations.ts:64 and never changes.
