NeSyCat · Wireframe · v0.7 · 1728×1080 (16″ MBP scaled)

Editor chrome — pills on a clean white canvas.

Each scene is a 1728×1080 frame sized for a 16″ MacBook Pro at default scaling. Sidebar widths, panel sizes, button padding, font weights, JSON-panel header copy, and React Flow controls are pulled directly from components/editor/EditorSidebar.tsx and components/editor/Canvas.tsx. The React Flow canvas itself (shapes, points, wires, JSON spine) is intentionally left as a dot-grid background — it's out of scope for the redesign.

The share is its own single-icon glass pill top-right. Bottom-left: the same idiom — one big glass pill holding the four zoom icons.
