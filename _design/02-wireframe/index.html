Editor chrome — current layout.

Low-fidelity wireframe of the editor's UI shell as it ships today. The React Flow canvas in the middle (shapes, points, wires, the JSON spine) is rendered as a labelled placeholder — it's intentionally out of scope. Everything around it is fair game to move, reshape, or replace. Edit the boxes in index.html and styles.css directly to iterate.

Sidebar

ALogo + project name. Click → editor home.
BSearch filters the diagram list in place.
C+ creates a new untitled diagram and navigates to it.
DDiagram rows: title + relative-time meta. Hover reveals edit/delete.
E‹ arrow collapses the sidebar to 0 width; toggle re-expands.

Canvas chrome

FTop-left toolbar slides right with the sidebar (CSS var --sidebar-offset).
G"Kinds ▾" on hover/click opens the menu in Scene 2.
HStraight / Smooth toggle controls edge path style.
IJSON button toggles the open-state panel in Scene 3.
JZoom controls: + / − / fit-view / lock. From React Flow's built-in <Controls />.

Redesign hooks

Floating Kinds menu obscures the top-left of the canvas — could move into the sidebar.
JSON panel and Kinds menu share the same surface but live on opposite corners — consider unifying as tabs.
No persistent diagram title / breadcrumb on the canvas — currently only visible in the sidebar row.
No surface for user identity / sign-out — sits implicitly behind the canvas.

Scene 4 — Star-prompt modal

After ~45s idle, a full-screen modal asks the user to star the GitHub repo. Dismissible with "Not now" (snoozes 3 days) or "Star on GitHub" (opens repo). Shown here as a stand-alone state since it overlays any of the scenes above.
